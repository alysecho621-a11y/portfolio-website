# Alyse Cho — Portfolio

Product design portfolio for Alyse Cho, 4th-year Design student at UC Davis. Built with Next.js 14 (App Router) and TypeScript.

## Pages

- `/` — Home (intro animation, hero, featured work, contact)
- `/about` — About (portrait carousel, FAQ, photo gallery)
- `/work/di-circle`, `/work/goodreads-redesign`, `/work/queer-arts-gallery` — case studies

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
